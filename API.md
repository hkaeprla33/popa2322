# API Reference

## Модуль `src.calculator`

### `add(a, b)`
| Параметр | Тип   | Описание           |
|----------|-------|--------------------|
| `a`      | float | Первое слагаемое   |
| `b`      | float | Второе слагаемое   |

**Возвращает:** `float` — сумму `a + b`.

### `divide(a, b)`
| Параметр | Тип   | Описание        |
|----------|-------|-----------------|
| `a`      | float | Делимое         |
| `b`      | float | Делитель (≠ 0)  |

**Возвращает:** `float`.
**Исключения:** `ValueError` — если `b == 0`.
